How it works

Go holds the network. PHP holds the logic.

{{DIAGRAM}}
  1. Declare. cairo serve server.php runs your file once. http(), get(), grpc() and service() describe the servers for Go.
  2. Serve. Go opens the listeners, builds the router and compiles your .proto files without protoc.
  3. One request, one fiber. When a handler waits on a socket, a sleep or a query, only its fiber pauses. The thread runs the others.
  4. Offload. Cairo\offload() sends CPU-heavy work to its own threads, so a long loop never stalls a request thread.

Laravel

Your Laravel app, on Cairo.

The cairophp/octane driver runs Laravel Octane on Cairo. Isolated mode boots your app once per thread and runs one request at a time, like every Octane server. Fiber mode runs several requests per thread, each with its own booted app, while the others wait on I/O.

Octane::concurrently() runs its tasks in fibers of the request, so their waits overlap instead of adding up.
